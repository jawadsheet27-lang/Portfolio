JAWAD SHEET - PERSONAL PORTFOLIO WEBSITE

HOW TO OPEN
1. Keep index.html, content.json and the assets folder together.
2. Double-click index.html to open it in any modern browser.

WHAT IS INSIDE
- index.html   : the website itself
- content.json : all the words and picture names, so they can be edited
- assets/      : your photos, the video files and the link-preview image
- admin/       : your private editing panel (yourdomain.com/admin)
- api/save.js  : the small piece of code that publishes what you edit
- DEPLOY-ADMIN.txt : how to switch the admin panel on (do this once)
- EDIT-GUIDE.txt   : how to edit the files by hand instead

HOW TO PUBLISH
Upload everything to GitHub and connect it to Vercel (free). Full steps are
in DEPLOY-ADMIN.txt. Any plain static host also works, but the admin panel
needs a host that can run api/save.js, such as Vercel or Netlify.
